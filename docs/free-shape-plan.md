# 큐빌로 자유 모양 만들기 계획

## 목적과 근거
- 목표: 평면에 그린 윤곽을 두께 있는 도형으로 만들고 다시 고칠 수 있게 한다.
- 이 문서는 계획만 제안하며 코드·설정·기존 로드맵을 변경하지 않는다.
- 근거는 `development-status.md`와 개발 계획의 UX·스케치 로드맵·입력·자원·사용성 항목이다.
- 아래의 ‘확인’은 상태 문서에 기록된 사실이며 이번 세션에서 앱을 재검증했다는 뜻이 아니다.
- 확인: Rust egui/wgpu 앱이며 Scene/Node/Transform, 명령 기반 Undo, .k3d 저장이 있다.
- 확인: 비파괴 Boolean, 한글 윤곽의 홀 분류·돌출, STL 평가 경로가 구현되어 있다.
- 확인: geometry worker 하나, 최신 대기 씬 하나, Revision 검사 정책이 있다.
- 확인: 현재 크기 핸들은 메시 Scale 대신 도형 파라미터를 바꾼다.
- 확인: Windows 4GB 실기기 성능·메모리와 실제 슬라이싱은 미완료 검증 항목이다.
- 기존 계획은 스케치→돌출을 v2.0에 두었다. 이 제안은 제한된 평면 윤곽 기능의 선행 후보다.
- 선택: 정식 출시 범위 편입 여부는 별도 결정하며 기존 필수 기능 완료를 대체하지 않는다.
- 선택: 주 작업자가 개선 중인 어린이 UI·직접 크기/회전·바닥 제약에 동일한 규칙으로 연결한다.
- PoC 불확실성: 기존 텍스트 경로의 재사용 범위, 자유 윤곽의 수치 안정성, 저사양 비용이다.

## Roblox에서 가져올 경험과 확인 한계
- 조사: 2026-11-15, Roblox Creator Hub 공식 문서 4개를 확인했다. Studio 실행·어린이 실험은 하지 않았다.
- 확인: 기본 Part를 삽입하고 화면에서 선택한 뒤 이동·크기·회전 핸들을 당겨 조립한다. [Work with parts](https://create.roblox.com/docs/tutorials/curriculums/building/work-with-parts)
- 확인: 이동/크기는 studs, 회전은 각도 간격을 조절하며 주변 면·모서리로 pivot soft snap도 지원한다. [Parts — Transform](https://create.roblox.com/docs/parts#transform-parts)
- 확인: Terrain Draw는 브러시로 더하고 빼며, Sculpt는 강도를 조절하고 Smooth는 급한 경계를 다듬는다. [Terrain Editor — Draw/Sculpt/Smooth](https://create.roblox.com/docs/studio/terrain-editor#draw)
- 같은 문서에는 브러시 모양·크기·높이·평면 잠금, Flatten의 낮추기/채우기, 변환 중 Live Edit/선 미리보기가 설명되어 있다.
- 확인: 공식 섬 만들기 예제는 Draw로 새 형태를 만들고 Sculpt로 기존 지형을 자라게/깎아 다듬도록 구분한다. [Create an environment with terrain](https://create.roblox.com/docs/tutorials/curriculums/core/building/create-an-environment-with-terrain#shape-the-island)
- 한계: 확인한 문서의 Draw는 지형 브러시다. 자유선 2D 폐윤곽을 그려 두께 돌출하는 기본 도구는 이 자료에서 확인되지 않았다.
- 따라서 ‘Roblox도 스케치 돌출을 제공한다’고 설명하지 않는다. 모든 Studio 기능·플러그인에 없다는 단정도 하지 않는다.
- 해석: 참고할 핵심은 손으로 화면의 결과를 바로 바꾸는 경험이다. 큐빌로 스케치 돌출 자체는 별도 제안이다.

| 제작 방식 | 자유로움과 비용에 대한 큐빌로 판단 | 첫 릴리스 선택 |
|---|---|---|
| 평면 그리기→두께 | 실루엣을 직접 표현하고 기존 윤곽/돌출·저장 경로와 연결 가능 | 자유 모양의 기본 경로 |
| 블록 쌓기/조립 | 기존 도형을 놓고 크기·회전·합치기로 구성; 유기적인 외곽에는 부품이 많음 | 기존 도형 흐름과 병행 |
| 조각/복셀 브러시 | 여러 방향에서 살 붙이기/깎기 가능; 해상도·메시화·얇은 살·이력 메모리 비용 추가 | 별도 실험, MVP 제외 |
- 제안: ‘붙이기/빼기’ 그림으로 기존 Boolean을 설명하되, ‘점 지우기’와 재료를 깎는 행동을 구별한다.
- 제안: 두께 손잡이 옆에 큰 크기 표시와 mm 값을 보이고, 격자 맞춤은 눈에 보이는 토글로 제공한다.
- 제안: 초등학생 필수 경로는 숨은 보조키 없이 완결한다. Roblox의 단축키·stud 단위를 그대로 옮기지 않는다.
- 제안: 자유선에는 끝점/닫힘 예상선·채움을 즉시 표시한다. 선 굵기는 입력 안내이며 입체 재료 폭이 아니다.
- 제안: 후속 브러시 실험을 한다면 큰 원형 범위 표시·크기 조절·‘붙이기/깎기’ 버튼을 함께 둔다.
- 제안: 따라 그릴 그림·짧은 단계 안내·상시 되돌리기는 기존 계획대로 유지하며 학년별 효과는 관찰로 검증한다.
- 저사양 선택: 화면 입력은 즉시, 비싼 메시 결과는 최신 유효 결과만 표시한다. 매 프레임 전체 Boolean을 계산하지 않는다.
- 오프라인 설치 자원만 사용한다. 복셀 실험이 생겨도 기존 원본 보존·Revision·4GB 예산을 우회하지 않는다.

## 서로 다른 UX 후보와 권장안
| 후보 | 아이의 행동 | 장점 | 비용·한계 |
|---|---|---|---|
| 점 잇기 중심 | 꼭짓점을 클릭하고 처음 점으로 닫기 | 닫힘·수정이 명확하고 트랙패드에 적합 | 곡선 실루엣에는 점이 많아짐 |
| 자유선 중심 | 펜처럼 한 바퀴 그리고 보정 확인 | 동물·구름을 자연스럽게 표현 | 떨림·열림·교차 복구가 필수 |
| 조각 붙이기 중심 | 원·네모를 놓고 합쳐 윤곽 만들기 | 어린 학년이 시작하기 쉬움 | 기존 Boolean과 겹치고 직접 그리기와 다름 |
- 권장: 하나의 ‘모양 그리기’ 화면에서 기본 ‘점 잇기’, 선택 ‘자유선’을 제공한다.
- 입력 방식만 다르고 닫힘 확인→점 고치기→두께 올리기 흐름은 공통이다.
- 저학년에는 같은 화면의 따라 그릴 그림을 먼저 제시한다. 별도 CAD 작업실을 만들지 않는다.
- 그림 예시는 앱 동봉 선 그림으로 시작하고 외부 이미지 가져오기는 후속으로 둔다.
- 기본 진입 카드에 점 세 개→색칠된 윤곽→두꺼운 도형 그림을 나란히 보여준다.
- 선 아이콘만 두지 않고 ‘점 잇기’, ‘자유선’, ‘점 고치기’, ‘두께’처럼 짧게 쓴다.

## 학년별 도움과 범위
- 1~2학년: 물고기·고양이 따라 그리기, 큰 목표 점, 시작점 강조, 완성 그림 예시를 제공한다.
- 안내는 ‘점을 눌러요’→‘처음 점을 눌러요’→‘위로 당겨요’처럼 한 번에 한 행동만 보인다.
- 3~4학년: 빈 종이와 간단한 자유선, 점 이동·삭제, 되돌리기로 자기 실루엣을 만든다.
- 5~6학년: 후속 구멍 도구, 치수 입력, 격자 맞춤과 세밀한 점 편집을 펼친다.
- 학년 선택을 강제하지 않는다. ‘도움 그림’과 ‘자세히’로 필요한 지원을 직접 켠다.
- 학년별 설계는 가설이다. 어린이 테스트를 했거나 효과가 입증됐다고 주장하지 않는다.

## 최저 위험 MVP와 후속 경계
- MVP: 수평 XY 캔버스, 외곽 하나, 직선 점 잇기와 자유선의 다각선 변환이다.
- MVP: 닫힌 채움, 점 추가·이동·삭제, 되돌리기/다시, 단순화 강도, 직선 돌출이다.
- MVP: 오류 위치 표시, 기존 장면으로 추가, 다시 윤곽 편집, Boolean·저장·STL 연동이다.
- MVP: 곡선처럼 보이는 자유선도 최종적으로 결정적인 다각선으로 평가한다.
- 후속 1: 외곽 안의 관통 구멍 여러 개와 원형 구멍 보조 도구를 추가한다.
- 후속 2: 제한된 곡선 편집·명시적 곡선 평탄화, 대칭, 외부 밑그림을 검토한다.
- 후속: 떨어진 외곽 여러 개는 별도 도형으로 나누는 정책부터 검토한다.
- 제외: 전체 CAD 구속 솔버, BRep, 임의 평면 스케치, Loft, 3D 조각, 자동 교차 복구다.
- 제외: 붓 선 자체의 튜브화, 자유선 압력 두께, 임의 모서리 Fillet, 막힌 내부 공동이다.
- MVP 키링 구멍은 기존 원기둥 빼기로 만든다. 스케치 홀을 구현한 것처럼 표시하지 않는다.

## 기본 작업 흐름과 작품 예
1. 팔레트 ‘모양 그리기’를 누르면 평면 종이와 ‘고양이 따라 그리기 / 빈 종이’가 나온다.
2. ‘점 잇기’로 귀·머리·몸의 바깥을 찍거나 ‘자유선’으로 한 바퀴 그린다.
3. 처음 점 부근에 오면 닫힘 예상선을 보이고 ‘닫기’를 눌러 확정한다.
4. 안쪽 색이 채워지면 ‘점 고치기’에서 귀 끝을 움직이고 필요 없는 점을 지운다.
5. ‘입체로’를 누르면 비스듬한 미리보기와 큰 위쪽 손잡이가 나온다.
6. 손잡이를 당겨 두께를 정하고 ‘장면에 놓기’를 누른다.
7. 고양이 받침에 기존 ‘글자’로 ‘민지’를 얹고 양의 깊이로 겹쳐 ‘합치기’한다.
8. 원기둥을 관통 배치해 ‘빼기’로 고리 구멍을 만든 뒤 저장하고 STL로 내보낸다.
- 예시 시작값 제안: 받침 가로 50mm, 두께 3mm. 출력 적합성의 보증값은 아니다.
- 글자를 지지할 면적과 구멍 주변 살이 남는지는 미리보기·형상 검사·슬라이싱으로 확인한다.
- 후속 홀 단계에서는 같은 고양이 외곽 안에 ‘구멍 그리기’로 고리 구멍을 직접 넣는다.
- 이때 이름은 기존 텍스트 노드로 유지한다. 손글씨 인식 기능은 추가하지 않는다.

## 화면 스케치와 조작
```text
┌ 모양 그리기       ↶ 되돌리기  ↷ 다시       [닫기] ┐
│ [점 잇기] [자유선] [점 고치기]     [도움 그림]     │
├─────────────────────────────┬───────────────────┤
│        시작 ●······         │ ① 그려요  그림    │
│           /       ●         │ ② 닫아요  채움    │
│          ●  색칠된 안쪽     │ ③ 올려요  입체    │
│           ＼_____●          │                   │
│  mm 격자 / 크게 보기        │ 매끈하게 [약──강] │
│  ‘처음 점을 눌러 닫아요’    │ [점 지우기]       │
├─────────────────────────────┴───────────────────┤
│ [취소]  가로 50mm · 세로 40mm       [입체로 →]   │
└─────────────────────────────────────────────────┘
  다음 화면: 비스듬한 미리보기 + ↑ 두께 손잡이 + [장면에 놓기]
```
- 와이어프레임의 비스듬한 미리보기는 실제 UI에서 그림으로 표현한다.
- 캔버스에서는 왼쪽 드래그가 그리기/점 이동이며 3D 카메라 회전과 경쟁하지 않는다.
- 트랙패드는 클릭·클릭 드래그로 모든 필수 행동이 가능하고 보조 버튼을 요구하지 않는다.
- 확대·이동은 명시적 버튼도 제공한다. 손가락 제스처는 필수 경로가 아니다.
- 점 선택 영역은 보이는 점보다 넓게 두고 겹치면 확대 안내를 보여준다. 두께 손잡이에도 같은 원칙을 쓴다.
- 선분을 눌러 점을 추가하고 점 선택 후 ‘점 지우기’를 누른다. 우클릭 메뉴는 보조다.
- 점 드래그·자유선 한 획·두께 드래그 한 번은 각각 Undo 한 건이며 Esc는 진행 중 조작을 취소한다.
- 화면 ‘취소’는 편집 진입 전 상태로 복귀한다. 신규 초안은 폐기 선택 전에 보존한다.
- 기존 도형 편집은 임시 초안에서 수행하고 ‘적용’ 한 번으로 장면 명령을 확정한다.
- 초안 안의 Undo 이력과 장면 Undo를 구분하고 단축키는 현재 편집 화면으로 보낸다.

## 빈 상태·오류·복구
- 빈 종이: ‘점을 3개 이상 찍어 봐요’와 세 점의 그림 예시를 보인다.
- 열린 선: 끝 두 점과 간격을 강조하고 ‘이어서 그리기 / 끝 잇기 / 되돌리기’를 제공한다.
- 자동 닫힘은 화면 거리로 후보만 표시한다. 실제 닫기 후 기하 검사를 반드시 한다.
- 너무 먼 끝을 몰래 잇지 않는다. ‘끝 잇기’의 직선을 미리 보여주고 아이가 확정한다.
- 교차: 교차 부분을 색과 표식으로 표시하고 ‘선이 겹쳤어요. 점을 옮겨요’라고 안내한다.
- 교차를 임의의 여러 면으로 분해하지 않는다. 최근 획 취소 또는 점 수정으로 복구한다.
- 점 3개 미만·일직선·면적 부족: ‘넓이가 있는 모양을 그려요’와 수정 위치를 보여준다.
- 점 삭제가 무효 윤곽을 만들면 초안은 보존하되 ‘입체로’를 막고 이유를 표시한다.
- 단순화가 귀나 좁은 목을 없애면 이전 윤곽을 유지하고 ‘덜 매끈하게’를 제안한다.
- 계산 실패: 초안·마지막 유효 모양을 남기고 ‘다시 계산 / 점 고치기’를 제공한다.
- 마지막 유효 3D와 현재 잘못된 윤곽은 ‘이전 모양’ 표시로 구분한다.
- 최신 초안이 무효면 이전 메시를 최신 결과처럼 적용하거나 STL로 내보내지 않는다.
- 후속 홀 오류: 바깥을 넘거나 다른 구멍에 닿으면 경계 표시 후 이동·삭제를 안내한다.

## 치수·두께·제작판 규칙
- 캔버스 좌표는 화면 픽셀과 분리된 mm이며 확대해도 실제 크기는 변하지 않는다.
- 외곽 가로·세로 변경은 로컬 윤곽 치수를 수정한다. 두께는 별도 mm 값으로 유지한다.
- 원본 획 좌표는 유지하고 크기 매개변수로 사상한다. Transform Scale은 1을 유지한다.
- 기본은 비율 잠금이다. ‘자세히’에서 비율 해제 시 좁아진 부분을 다시 검사한다.
- 두께는 양수 유한값만 허용하며 손잡이와 수치 입력이 동일한 검증을 거친다.
- 초기 제안: 두께 1~20mm, 기본 3mm. 프린터/재료별 안전 규격으로 해석하지 않는다.
- 최소 폭·구멍 주변 살의 경고 기준은 출력 프로파일과 슬라이싱 PoC 후 확정한다.
- 상한은 기존 도형 치수 제한·현재 제작판 크기 중 더 엄격한 조건을 따른다.
- 고정된 제작판 크기를 새로 가정하지 않고 장면의 실제 판 경계를 사용한다.
- 새 도형은 바닥 최저점 Z=0에 놓고 판 내부에서 가능한 위치를 제안한다.
- 크기·회전 뒤 전체 변환 경계의 최저 Z를 계산해 바닥 아래로 내려가지 않게 한다.
- 판을 벗어나면 경계를 표시하고 ‘가운데 놓기 / 작게 맞추기’를 제공한다.
- ‘작게 맞추기’는 미리보기에 변경 치수를 표시하고 확인 후 적용하며 두께는 유지한다.
- 맞는 위치가 없으면 추가를 막고 크기 조절로 돌아간다. 형상을 조용히 잘라내지 않는다.

## 결정적인 형상 처리
- 선택: 입력 획→정리된 외곽→검증된 단면→돌출 메시를 분리한다.
- 화면 이벤트 시간 대신 입력 순서와 저장된 mm 좌표로 결과를 재생성한다.
- 입력 시 중복 표본 제거·최소 거리 재표본화를 수행하되 원시 보존량도 제한한다.
- 유한값 검사 후 고정 mm 격자 양자화 규칙·반올림 방식·허용 오차를 버전으로 고정한다.
- 중복점·영 길이 변을 제거하고 닫힌 마지막 변을 명시적으로 검사한다.
- 결정적 다각선 단순화는 거리 오차 한도와 동률 처리 순서를 고정한다.
- MVP ‘매끈하게’는 점 줄이기와 제한된 평균화 후보를 뜻하며 정확한 원호를 보장하지 않는다.
- 평균화는 기본 OFF 후보로 비교한다. 각 후보를 교차·면적·변위 검사 후 채택한다.
- 닫힘·자기 교차·겹치는 변·비인접 접촉·최소 면적을 단순화 전후 모두 검사한다.
- 좁은 부분을 넘어 위상이 달라지는 후보는 거절하고 마지막 유효 단면을 유지한다.
- 선택: 외곽 반시계, 홀 시계 방향으로 정규화하고 시작 정점을 안정적으로 정렬한다.
- 후속 홀은 외곽에 엄격히 포함되고 서로 분리되어야 한다. 접촉·중첩·섬 중첩은 거절한다.
- 곡선 후속 단계는 mm 현 오차·최대 분할 수·순회 순서를 고정해 평탄화한다.
- 검증된 단면의 윗면·아랫면과 경계별 측벽을 생성하고 방향·공유 정점을 검사한다.
- 삼각 분할 성공만으로 유효하다고 보지 않는다. 폐합성·체적·퇴화 면도 확인한다.
- 기존 텍스트의 홀/돌출 코드는 재사용 후보이며 임의 입력 처리 가능성은 PoC로 확인한다.

## 비파괴 데이터·장면 통합
- 새 SketchExtrude 계열 primitive를 제안한다. 실제 이름·타입은 구현 시 결정한다.
- 저장: 원본 획, 입력 방식, 편집 윤곽과 안정적 점 ID, 닫힘 상태, 외곽/홀 역할을 포함한다.
- 저장: 치수, 두께, 단순화·평균화·양자화·평탄화 설정과 알고리즘 버전을 포함한다.
- 원본 획과 점 수정 후 윤곽을 둘 다 보존한다. 다시 매끈하게 적용 시 수동 편집 덮어쓰기를 안내한다.
- 생성 메시·GPU 버퍼는 재생성 캐시이며 편집 원본의 유일한 저장물이 아니다.
- 형식 버전·구버전 기본값·미지원 새 primitive 오류 정책과 왕복 테스트를 함께 추가한다.
- 초안은 프로젝트의 별도 복구 자료로 저장하고 유효한 장면 노드와 혼동하지 않는다.
- 생성 후 일반 선택·이동·회전·복제·그룹·Boolean의 자식으로 참여한다.
- ‘그림 고치기’로 원본을 재편집하고 Boolean 부모와 필요한 캐시만 무효화한다.
- STL은 클릭 시점의 유효한 장면 스냅샷을 평가한다. 편집 초안은 출력에서 제외한다고 명시한다.
- 원자적 저장·출력 실패 시 기존 파일 보존 정책을 그대로 따른다.

## 작업 스레드와 4GB 자원 예산
- UI는 획 표시와 가벼운 입력만 담당하고 단순화·위상 검사·메시 생성은 기존 worker로 보낸다.
- 초안 Revision과 Scene Revision을 함께 비교하며 오래된 완료 결과는 즉시 폐기한다.
- 실행 중 작업 하나·최신 대기 하나를 유지하고 취소 확인을 단계/루프 경계에 넣는다.
- export 스냅샷은 기존 별도 보존 정책을 따르고 초안 미리보기 취소와 혼동하지 않는다.
- 선택한 초기 제한 후보: 획당 원시 표본 8,192개, 평가 외곽 512점, 후속 홀 최대 8개다.
- 후속 홀 포함 총 평가점 1,024개를 후보로 두며 기존 삼각형/Boolean 한도도 적용한다.
- 초과 입력은 조용히 버리지 않고 ‘점이 많아요’와 되돌리기·단순화·분할 안내를 보인다.
- 원본 획·복구·Undo 합계에도 바이트 예산을 두고 긴 드래그마다 전체 획을 복제하지 않는다.
- 초기 후보 예산: 초안/이력 16MiB, 자유 모양 CPU 캐시 32MiB, GPU 캐시 32MiB다.
- 위 수치는 실측 전 제한안이다. 기존 씬·텍스트·Boolean·export와 합친 피크를 별도 측정한다.
- RAM 4GB 전체를 앱에 할당하지 않는다. OS·공유 GPU 여유를 포함한 프로세스 상한은 PoC에서 정한다.
- 예산 초과 시 오래된 캐시 제거→미리보기 상세도 축소→작업 거절 순으로 대응하고 원본은 보존한다.

## 좁은 구현 단계와 통과 기준
- A 기하 PoC: 단일 외곽 정리·돌출·직렬화 표본만 구현하고 UI 확대 없이 수치 정책을 고정한다.
- A 통과: 볼록/오목/떨림/중복/열림/교차/거의 일직선 표본이 결정적으로 성공 또는 거절된다.
- B MVP 입력: 점 잇기·자유선·채움·점 편집·Undo·두께 손잡이를 하나의 초안 화면에 연결한다.
- B 통과: 마우스와 트랙패드로 도형 생성·수정·취소·복귀가 가능하고 무효 초안은 적용되지 않는다.
- C 통합: 장면 primitive·Boolean 자식 편집·저장/복구·STL과 판 제약을 연결한다.
- C 통과: 왕복 후 점/설정 보존, 한 번 Undo, stale 결과 차단, 출력 스냅샷 불변을 확인한다.
- C 형상 합격: 닫힌 메시, 변 양방향 2회, 양의 체적, 퇴화/교차 없음과 치수 오차 한도 충족이다.
- C 작품 합격: 고양이 이름 키링을 합치기·빼기 후 Bambu Studio에서 관통 홀·두께까지 확인한다.
- D 사용성/자원: 실제 4GB 장비의 최대 입력·Undo·Boolean·출력 중첩 피크와 취소 응답을 측정한다.
- D 사용성: 학년군별로 시작 찾기→닫기→점 수정→두께→복구 과제를 관찰한다.
- 도움 없이 완료 여부·도움 횟수·오류 회복·포기 지점을 기록하고 첫 파일럿 후 수치 목표를 정한다.
- 필수 관찰 기준: 그림/짧은 안내만으로 다음 행동을 찾고, 오류 후 원본 손실 없이 과제를 이어간다.
- E 후속 홀: 포함·접촉·중첩·좁은 살·저장 왕복 표본과 5~6학년 구멍 과제를 추가한다.
- 검증은 해당 단계의 기하·core/io·worker 검사와 필요한 UI 관찰로 제한한다.
- 전체 테스트 반복·주변 리팩터링은 하지 않는다. 일정은 PoC 결과 없이 정밀 추정하지 않는다.
- 큰 Phase 완료 때만 한 번 push하는 기존 정책을 따른다. 이 계획 작성에는 commit/push하지 않는다.

## 남은 결정
- MVP를 기존 출시 전 필수 범위에 넣을지, 후속 독립 Phase로 둘지 결정해야 한다.
- 닫힘 화면 거리·mm 오차·두께/최소 살 경계와 실제 제작판 API는 PoC/주 작업 변경과 맞춘다.
- 단순화만 쓸지 제한 평균화를 켤지, 알고리즘 재사용 범위와 전체 메모리 상한은 실측 후 확정한다.
- 구멍·곡선·외부 밑그림은 MVP 결과를 확인한 뒤 각각 별도 구현 범위로 결정한다. 복셀/조각은 별도 PoC 여부부터 판단한다.
