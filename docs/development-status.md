## 편집기 기반 — 구현·통합 중

- studio-core: 버전 있는 Scene/Node/Transform, 추가·변경·삭제·복제·그룹/해제 명령.
- 순환·중복 참조, 고아 노드, 버전·치수·복잡도 검증.
- 드래그 한 건의 Undo/Redo, 파라미터만 저장하는 최대 100개 이력.
- Evaluator 캐시: 이동·회전 시 메시 재사용, 변경된 도형만 재생성.
- 객체별 GPU 버퍼·변환 uniform·선택 색상, CPU ray picking.
- UI: 다중 선택·이동 도구·스냅·위치/회전 입력·바닥 놓기·그룹·복제.
- .k3d JSON 저장/불러오기·원자적 교체·로컬 자동 복구/복구 선택 UI.
- STL 내보내기는 클릭 시점 씬을 평가하고 임시 파일에서 검증 후 신규 파일로 반영.
- CPU 테스트 13개 통과(geometry 4 / core 4 / io 5), 관련 Clippy 통과.
- 실제 M1 Metal GPU smoke 1개 통과(장면·선택·빈 장면; 일반 CI에서는 ignored).
- 통합 .app 화면에서 다중 도형 추가·목록·선택 표시 확인.
- 복사/붙여넣기·접근성 지원 앱 실행 검증. 실제 UI에서 X=85mm 입력, Undo→0, Redo→85, 저장 후 변경을 폐기하고 불러오기→85 복원 확인. 검증 파일: /tmp/cubilo-ui.xKG85M/scene.k3d.
- 상대 경로 기본값 제거. 저장·다른 이름 저장·열기·STL은 rfd 네이티브 대화상자로 전환. 잘못된 열기·저장은 기존 프로젝트 경로를 바꾸지 않는다. 새 UI 실제 대화상자 검증은 다음 작업.

## 기본 도형·속성 — 구현 중

- 6종 도형 구현: 상자·원기둥·구·원뿔(상단 지름 0 포함)·토러스·반구.
- 상자: 수직 모서리 둥글기 + Hollow, 내부 반경 max(외부 반경−벽 두께, 0), 반경 OFF 값 보존.
- 원기둥: Taper + Hollow의 경사면 수직 두께 계산, 단독 가장자리 둥글기.
- 원기둥 Rounded + Hollow/Taper는 UI에서 제한하고 이유 표시.
- earcutr 0.5.0으로 열린 윗면 테두리 삼각 분할. 구·원뿔의 극점은 단일 정점 공유.
- 실제 바닥 10mm 그리드 렌더링 추가, M1 Metal GPU smoke 통과.
- 관련 CPU 테스트 19개(geometry 8 / core 4 / io 7) 통과. 새 속성 누락된 v1 파일도 기본값으로 복원.
- 관련 Clippy 통과. 6종 도형 UI는 .app에 반영, 그리드는 GPU 단독 검사 후 앱 패키지 재빌드 예정.

## Boolean·한글·비동기 — 구현 중

- manifold-rust 0.19.2 strict 엔진: 합치기/빼기/교집합, 빈 결과 처리, 취소 토큰.
- 입력 도형당 100,000 / 결과 250,000 삼각형, Boolean 2~32개 자식·깊이 16 한도(잠정 안전 한도, 성능 합격선 아님).
- 비파괴 Boolean 노드·원본 자식 편집·트리 목록. 부모 이동은 결과 메시 캐시 재사용.
- rustybuzz 0.20.1 + 동봉 나눔고딕: NFC 정규화, 윤곽선 적응 분할·홀 분류·삼각 분할·돌출.
- 글자 높이는 생성된 전체 윤곽선의 실제 높이. 글꼴 ID 고정, 한 줄 최대 64자.
- 테스트: ㅇ/ㅁ 홀, 한글·영문, 분해형 한글, 한글 키링 받침 합치기+관통 구멍, 자식 편집·Undo.
- 단일 geometry worker: 실행 중 이전 미리보기 취소, 최신 대기 씬 1개, 최신 결과만 보관·Revision 검사.
- STL은 클릭 시점 스냅샷을 별도 보존하고 같은 스레드에서 계산. 편집이 export를 바꾸지 않는 테스트 통과.
- 출력 취소·실패는 최종 파일을 교체하지 않는다. Native Save의 사용자 덮어쓰기 선택 후 원자적으로 반영.
- IME Preedit/Commit 중 전역 단축키 억제 추가. 실제 OS 한글 IME 검증은 아직 안 함.
- CPU 관련 테스트 29개 통과(geometry 12 / core 6 / io 9 / app worker 2), 관련 Clippy·Mac debug .app 빌드 통과.
- 새 Boolean·텍스트·파일 대화상자·비동기 통합 UI의 실제 실행 검증은 다음 작업.
